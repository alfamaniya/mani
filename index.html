محاسبه مقاومت سری برای LED یا آرمیچر

قانون اهم

ولتاژ باتری، ولتاژ کاری قطعه و جریان موردنیاز آن را وارد کنید تا مقاومت سری تقریبی و توان مناسب مقاومت محاسبه شود. فقط ولتاژ کافی نیست؛ جریان مجاز قطعه هم ضروری است.

برای LED، جریان را از دیتاشیت یا مشخصات قطعه بردارید؛ برای بسیاری از LEDهای معمولی حدود ۱۰ تا ۲۰ میلی‌آمپر است، اما مشخصات همان قطعه ملاک است. برای آرمیچر، جریان نامی و به‌ویژه جریان راه‌اندازی/گیرپاژ را از دیتاشیت بررسی کنید؛ مقاومت سری معمولاً روش مناسبی برای کنترل موتور نیست و ممکن است باعث افت گشتاور یا روشن‌نشدن آن شود. در مدار واقعی، تلرانس قطعات را هم در نظر بگیرید.

\n

ماشین حساب معادله درجه دو

محاسبه ریشه‌ها

دو عدد b و c را وارد کنید تا ریشه‌های معادله زیر محاسبه شوند. در این ابزار ضریب x² برابر ۱ در نظر گرفته شده است.

x² + bx + c = 0

نکته: برای معادله کامل ax² + bx + c = 0 با ضریب a متفاوت از ۱، باید هر سه ضریب وارد شوند؛ این ماشین حساب طبق درخواست، دو عدد b و c را برای معادله x² + bx + c = 0 دریافت می‌کند.
