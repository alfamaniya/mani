ماشین حساب معادله درجه دو

محاسبه ریشه‌ها

دو عدد b و c را وارد کنید تا ریشه‌های معادله زیر محاسبه شوند. در این ابزار ضریب x² برابر ۱ در نظر گرفته شده است.

x² + bx + c = 0

نکته: برای معادله کامل ax² + bx + c = 0 با ضریب a متفاوت از ۱، باید هر سه ضریب وارد شوند؛ این ماشین حساب طبق درخواست، دو عدد b و c را برای معادله x² + bx + c = 0 دریافت می‌کند.
